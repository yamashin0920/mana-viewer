# 講師マニュアル

> 読者: 講師（`instructor`）
> 最終更新: 2026-09-09
> 関連: [学習者マニュアル](learner.md) / [管理者マニュアル](admin.md)

講師は学習者と同じビューアを使います。授業中の読み方・注釈の付け方は [学習者マニュアル](learner.md) をそのまま使ってください。

## このマニュアルでできること

- 講師アカウントでログインする
- LMS のコースから指定ページでビューアを開く
- 名簿を同期する
- 配布教材を読み、注釈を付けて共有リンクで学習者と共有する

## 使うアプリと URL

| 画面 | URL |
|------|-----|
| ログイン | http://localhost:5180/login |
| ビューア | http://localhost:5173 |
| LMS | http://localhost:5200 |
| マニュアル | http://localhost:5210 |

開発用アカウント:

- ID: `instructor`
- パスワード: `instructor`

表示名は「鈴木 花子」、ロールは講師です。

## ログイン

1. http://localhost:5173 を開きます。
2. `instructor` / `instructor` でログインします。

結果: 本棚が開き、ヘッダーに講師ロールが表示されます。

## 日常の使い方

学習者と同じです。

1. 本棚から教材を開きます。
2. 授業用のマーカーや付箋を付けます。
3. 注釈を共有リンクにして学習者に渡します（学習者にも同じ教材のライセンスが必要です）。
4. 必要なら Markdown / JSON で書き出して配布資料にします。

ページ送り、検索、目次、ダークモード、印刷は学習者マニュアルを参照してください。

## LMS から教材を開く

1. http://localhost:5200 を開き、`instructor` / `instructor` でログインします（未ログインならログイン画面へ飛びます）。
2. コース「2026年度 1年A組」を開きます。
3. 教材の開始ページを指定し、「ビューアで開く」を押します。
4. ビューアが指定ページで開き、「LMS から起動しました」と出ます。

結果: 学習記録（xAPI）が LMS の「学習記録」に残ります。学習者 `demo` も同じコースから起動できます。

講師は「名簿を同期」でメンバー数のモック同期ができます。ユーザー追加そのものは管理者作業です。

## 管理画面について

http://localhost:5190 を開いても、講師ロールではアクセス拒否になります。ユーザー追加やライセンス発行は組織管理者の作業です。依頼先は [管理者マニュアル](admin.md) です。

API 上のライセンス参照に加え、LMS（:5200）でコースと名簿同期が使えます。

## できないこと・注意

- 席の追加、ユーザー作成、教材の公開設定はできません
- 学習者の注釈を管理画面から一覧する機能はありません

## 困ったとき

教材が本棚に無いときは、管理者にライセンス割当を依頼してください。起動の問題は [トラブルシュート](../troubleshooting.md) です。
