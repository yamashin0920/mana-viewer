# 講師マニュアル

> 読者: 講師（`instructor`）
> 最終更新: 2026-09-09
> 関連: [学習者マニュアル](learner.md) / [管理者マニュアル](admin.md)

講師は学習者と同じビューアを使います。授業中の読み方・注釈の付け方は [学習者マニュアル](learner.md) をそのまま使ってください。

## このマニュアルでできること

- 講師アカウントでログインする
- 配布教材を読み、注釈を付けて共有リンクで学習者と共有する
- 管理画面に入れないことを確認する

## 使うアプリと URL

| 画面 | URL |
|------|-----|
| ログイン | http://localhost:5180/login |
| ビューア | http://localhost:5173 |

開発用アカウント:

- ID: `instructor`
- パスワード: `instructor`

表示名は「鈴木 花子」、ロールは講師です。

## ログイン

1. http://localhost:5173 を開きます。
2. `instructor` / `instructor` でログインします。

結果: 本棚が開き、ヘッダーに講師ロールが表示されます。

## 日常の使い方

学習者と同じです。

1. 本棚から教材を開きます。
2. 授業用のマーカーや付箋を付けます。
3. 注釈を共有リンクにして学習者に渡します（学習者にも同じ教材のライセンスが必要です）。
4. 必要なら Markdown / JSON で書き出して配布資料にします。

ページ送り、検索、目次、ダークモードは学習者マニュアルを参照してください。

## 管理画面について

http://localhost:5190 を開いても、講師ロールではアクセス拒否になります。ユーザー追加やライセンス発行は組織管理者の作業です。依頼先は [管理者マニュアル](admin.md) です。

API 上は講師向けの名簿同期・ライセンス参照がありますが、専用画面はありません。

## できないこと・注意

- 席の追加、ユーザー作成、教材の公開設定はできません
- LMS からの起動（LTI）はまだビューアに繋がっていません
- 学習者の注釈を管理画面から一覧する機能はありません

## 困ったとき

教材が本棚に無いときは、管理者にライセンス割当を依頼してください。起動の問題は [トラブルシュート](../troubleshooting.md) です。
