# 管理者マニュアル

> 読者: 組織管理者（`org_admin`）およびコンテンツ管理者（`content_admin`）
> 最終更新: 2026-09-09
> 関連: [マニュアル目次](README.md) / [管理画面機能](../features/admin.md)

アカウント、ログイン ID、教材メタデータ、ライセンス席を管理する手順です。PDF の中身を読む操作は [学習者マニュアル](learner.md) です。

## このマニュアルでできること

- 管理画面に入る
- ユーザーを追加・編集・削除する
- ログイン ID とパスワードを発行する
- 教材情報を登録・公開する
- ライセンスを発行し、席をユーザーに割り当てる

コンテンツ管理者は教材の作成・編集が中心で、ユーザー削除やライセンス発行は組織管理者の権限です。画面にエラーが出たら権限不足のことがあります。

## 使うアプリと URL

| 画面 | URL |
|------|-----|
| ログイン | http://localhost:5180/login |
| 管理画面 | http://localhost:5190 |
| ビューア（確認用） | http://localhost:5173 |

開発用の組織管理者:

- ID: `admin`
- パスワード: `admin`

## ログイン

1. http://localhost:5190 を開きます。未ログインならログイン画面へ移動します。
2. `admin` / `admin` でログインします。
3. アカウント画面（`/accounts`）が開きます。

結果: 左に「アカウント」「ライセンス」「教材」のナビがあります。

学習者 `demo` で管理画面を開くと拒否されます。

## アカウント

### ユーザーを追加する

1. アカウントページでユーザー追加を開きます。
2. 名前、メール、ロール（学習者 / 講師 / 組織管理者 / コンテンツ管理者）を入れます。
3. 保存します。

結果: 一覧にユーザーが増えます。この時点ではまだログインできません。

### ログインアカウントを発行する

1. 同じページでログインアカウント追加を開きます。
2. ログイン ID、パスワード、紐付けるユーザーを選びます。
3. 保存します。

結果: その ID で http://localhost:5180/login から入れます。1 ユーザーに 1 ログインです。既定の `admin` アカウントは削除できません。

### ユーザーのライセンスを変える

1. ユーザー行からライセンス編集を開きます。
2. 割り当てるライセンスにチェックします。
3. 保存します。

結果: 席が空いていればその教材が学習者の本棚に出ます。席が埋まっているとエラーになります。

### ユーザーを削除する

組織管理者のみ。自分自身は削除できません。削除するとライセンス割当からも外れます。

## 教材

1. 左ナビ「教材」を開きます。
2. 追加でタイトル（必須）、表紙タイトル、著者、カテゴリ、ページ数、説明、公開状態、印刷/オフライン等のポリシーを入れます。
3. 学習者の本棚に出すときは状態を「公開」にします。
4. 保存します。

結果: 一覧に教材が増えます。表紙画像はタイトルからプレースホルダが作られます。

PDF ファイルそのもののアップロードはありません。開発のビューアはサンプル PDF を表示します。

教材を消すと、その教材のライセンスも消えます（組織管理者）。

## ライセンス

1. 左ナビ「ライセンス」を開きます。
2. 追加で教材、席数、開始日、終了日、オフライン可否、割当ユーザーを指定します。
3. 保存します。
4. 後から席数や割当を編集できます。

結果: 残席が表示されます。学習者が読むには、公開済み教材 + 有効なライセンス割当の両方が必要です。

## 確認

1. 別ブラウザ（またはログアウト後）で `demo` 相当の学習者としてビューアを開きます。
2. 割り当てた教材が本棚にあることを確認します。

管理者自身の `admin` でもビューアは開けます（ロールは組織管理者）。

## ログアウト

管理画面のログアウトは共通セッションも終了します。

## できないこと・注意

- 請求・決済画面はありません
- LMS 連携の設定画面はありません
- 開発用パスワードは平文で保存されます。本番運用には使えません
- 印刷ポリシーをオンにしても、ビューア側の印刷制御は未実装です
