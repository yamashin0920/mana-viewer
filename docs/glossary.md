# 用語集

> 読者: 全員
> 最終更新: 2026-09-09
> 関連: [ドメインモデル](domain-model.md) / [アーキテクチャ](architecture.md)

画面・API・文書で使う言葉を揃えます。新しい概念を足したら、この表とドメインモデルを同時に更新します。

## プロダクト

| 用語 | 意味 |
|------|------|
| マナビューア (mana-viewer) | 本リポジトリのプロダクト名。B2B 向け PDF 学習プラットフォーム |
| ビューア | 学習者が PDF を読む React アプリ（`viewer/`、開発時ポート 5173） |
| 認証サービス | ログイン専用の API + Web（`auth/`） |
| 管理画面 | 組織のアカウント・教材・ライセンスを扱うアプリ（`admin/web/`、5190） |
| LMS | コースから教材を開くアプリ（`lms/web`、開発時ポート 5200） |
| LTI / Deep Link 起動 | LMS が発行するビューア URL。`lmsLaunch=1` と `page` を付ける |

## ロール

| 用語 | コード値 | 説明 |
|------|----------|------|
| 学習者 | `learner` | 配布教材の閲覧・注釈。管理画面には入れない |
| 講師 | `instructor` | 学習者と同じ閲覧に加え、一部組織 API（名簿・ライセンス参照など） |
| 組織管理者 | `org_admin` | 管理画面の全操作。ユーザー削除、ライセンス発行など |
| コンテンツ管理者 | `content_admin` | 管理画面に入れる。教材の作成・編集。ユーザー削除やライセンス発行は不可 |

## コンテンツと閲覧

| 用語 | 意味 |
|------|------|
| 組織 (Organization) | テナント単位。ユーザー・教材・ライセンスは組織に属する |
| 教材 / コンテンツ | PDF 学習教材。API 上は `Content` |
| 本棚 | 教材カードの一覧画面。ルート `/` |
| 配布本棚 | 組織が配った教材棚（`type: distributed`）。学習者は変更できない |
| 表紙タイトル (`coverTitle`) | カード画像に載せる短いタイトル |
| 目次 (TOC) | 教材の見出し一覧。ページジャンプまたは外部 URL |
| 閲覧セッション | PDF ストリーミング用の短命セッション。`sessionToken` とウォーターマークを返す |
| チャンク | ページ単位の暗号化バイナリ。開発時はダミー。ビューアはデモ PDF を表示 |
| 進捗 | ページ・ズーム・表示モード・既読率など。API に自動保存 |

## 注釈

| 用語 | コード値 | 説明 |
|------|----------|------|
| マーカー | `highlight` | テキスト選択またはドラッグで色付きハイライト |
| ブックマーク | `bookmark` | 現在ページへのしおり |
| ページメモ | `note` | ページに紐づくテキストメモ |
| 下線 | `underline` | 型のみ。新規作成 UI は未実装 |
| 描画（ペン） | `drawing` | フリーハンド |
| 付箋 | `sticky` | ページ上に配置する短いメモ |
| 共有リンク | `?share=` | 注釈セットを期限付き URL で共有 |

## ライセンスと DRM

| 用語 | 意味 |
|------|------|
| ライセンス | 組織が持つ教材利用権。席数 (`seatCount`) と割当ユーザー |
| 席 | 同時に割り当てられるユーザー数の上限 |
| 検証 (`verify`) | 閲覧前に `canView` を確認する API |
| ポリシー | 印刷・オフライン・端末数・ウォーターマークなどの教材制約 |
| ウォーターマーク | PDF 上のオーバーレイ文字列（ユーザー名・日付など） |
| オフラインパッケージ | 端末登録後に取得するダウンロード単位。API はあるが完全オフライン閲覧は未実装 |

## 認証

| 用語 | 意味 |
|------|------|
| ログイン ID | `credentials.json` の `loginId`。メールアドレスではない |
| アクセストークン | Bearer トークン。開発時は `mock-token-*` |
| セッション (SSO) | `auth/web` が保持するログイン状態。ビューアと管理画面で共有 |
| 認可 | ログイン後の権限チェック。各アプリの `AuthGuard` と API ミドルウェア |

## LMS（部分実装）

| 用語 | 意味 |
|------|------|
| LTI 起動 | LMS から教材を開く。`POST /lms/launch` とビューアのクエリで実装 |
| Deep Link | 教材 ID とページから起動 URL を生成 |
| xAPI | 学習記録。LMS 起動時にビューアが送信し、LMS の学習記録画面で見る |
