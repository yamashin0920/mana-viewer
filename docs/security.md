# セキュリティ

> 読者: 開発者・運用者
> 最終更新: 2026-09-09
> 関連: [認証](features/auth.md) / [DRM・オフライン・LMS](features/drm-offline-lms.md)

現状は **開発用モック** です。次の実装を本番セキュリティと見なさないでください。

## 認証

- パスワードは `credentials.json` に平文
- トークンは固定の `mock-token-*`（資格情報作成時はランダム文字列を発行）
- CORS は全許可
- HTTPS・Cookie の HttpOnly・CSRF 対策は未実装
- リフレッシュトークンは `refresh-` + アクセストークンの連結

本番では IdP / ハッシュ化パスワード / 短命 JWT / セキュア Cookie への置き換えが必要です。

## 認可

- 画面: 管理画面は `canAccessAdmin`（`org_admin` `content_admin`）
- API: Bearer → ユーザー解決 → ロール → 自組織 → 教材はライセンス
- 注釈の更新削除は所有者のみ
- 共有注釈の GET は認証任意だが、ログイン中でライセンスが無いと 403

## DRM（部分）

| 項目 | 状態 |
|------|------|
| ウォーターマーク表示 | ✅ |
| ポリシー API | ✅ |
| チャンク暗号化 | 🔶 ヘッダとダミーバイトのみ |
| 印刷 | ✅ | 管理の `allowPrint`。ビューアでボタンと Ctrl+P を制御 |
| コピー制御（選択禁止） | ❌ |
| スクリーンショット防止 | ❌ |

開発時 `VITE_USE_DEMO_PDF=true` では暗号化パイプラインを通らずサンプル PDF を出します。

## データ

- seed と資格情報はリポジトリに含まれます（架空の学校データ）
- 実在の個人情報を seed に入れない
- `.dev/` ログにトークンが出ないか注意する

## ブラウザ保存

`localStorage` の `accessToken` は XSS で読めます。開発用として文書化しています。
