# 本棚

> 読者: 開発者
> 最終更新: 2026-09-09
> 関連: [プラットフォーム API](../api/platform.md) / [学習者マニュアル](../manuals/learner.md)

## 目的

ライセンスのある教材を探し、ビューアへ進みます。

## 対象ユーザー

ビューアに入れる全ロール（学習者・講師・管理者）。管理者も学習者と同じ本棚を使えます。

## 状態

| 項目 | 状態 |

| タイトル・著者・タグ検索 | ✅ |
| カテゴリフィルタ | ✅ |
| カード上の進捗バー | ✅ |
| 最近読んだもの | ✅ |
| カスタム棚 API | 🔶 API あり、本棚 UI からの作成は薄い |

## 画面とルート

- パス: `/`（`BookshelfPage`）
- ヘッダー: 組織名、ユーザー名、ロール、テーマ、ログアウト

## 主な操作

- 検索ボックスで絞り込み
- カテゴリ（数学 / 英語 等）
- カードクリック → `/viewer/:contentId`
- 最近読んだものセクションを横スクロール

## データと API

- `GET /bookshelves`
- `GET /contents?q=&category=`
- `GET /users/me`（ヘッダー）

カードに出すのは `published` かつライセンスのある教材です。

## 権限

ライセンスの無い教材は API が返しません。
