# 管理画面

> 読者: 開発者
> 最終更新: 2026-09-09
> 関連: [管理 API](../api/admin.md) / [管理者マニュアル](../manuals/admin.md)

## 目的

組織管理者がアカウント・ログイン資格情報・教材・ライセンスを保守します。

## 対象ユーザー

`org_admin` と `content_admin`。それ以外は拒否ページ。

## 状態

| 項目 | 状態 |
|------|------|
| アカウント（ユーザー CRUD） | ✅ |
| ログインアカウント CRUD | ✅ |
| ユーザーへのライセンス割当 | ✅ |
| 教材 CRUD・表紙タイトル | ✅ |
| 印刷 OK/NG | ✅ |
| ライセンス CRUD | ✅ |
| ダークモード | ✅ |
| グループ / LMS 設定 UI | ❌ API のみ |

## 画面とルート

| パス | ページ |
|------|--------|
| `/accounts` | ユーザーと資格情報（既定） |
| `/licenses` | ライセンス |
| `/contents` | 教材 |
| `/` | `/accounts` へリダイレクト |

レイアウト: サイドナビ、ログインユーザー、ログアウト、テーマ。

## 主な操作

- ユーザー作成（名前・メール・ロール）→ 続けてログイン ID を発行しないとビューアに入れない
- 資格情報は既存ユーザーへ 1 対 1
- 教材の公開状態を `published` にしないと本棚に出ない
- 印刷を OK にするとビューアに印刷ボタンが出る。NG だと印刷できない
- ライセンス席をユーザーに割り当てないと閲覧できない

## データと API

admin クライアントは `VITE_AUTH_API_BASE` と `VITE_MOCK_API_BASE`。実装は `admin/web/src/api/client.ts`。

## 権限

[管理 API](../api/admin.md) の表と同じです。UI は API エラーメッセージを表示します。

## テスト

`admin/web/e2e/`（login, navigation, accounts, contents, licenses, admin-api）。
