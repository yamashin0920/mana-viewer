> 最終更新: 2026-09-09

## 目的

教材上に個人のマーカー・メモ・描画を残し、一覧・編集・書き出し・共有します。

## 対象ユーザー

教材を閲覧できるユーザー。注釈は作成者の所有です。

## 画面とルート

ビューアツールバーの注釈ツール（`select` / `marker` / `pen` / `sticky`）。サイドバー「注釈」。共有は `ShareAnnotationsDialog`。閲覧は `/viewer/:contentId?share=`。

## 主な操作

- 選択ツール: テキスト選択後にフローティングカラー
- マーカー: ドラッグで即ハイライト
- ペン: フリーハンド。色は赤・青・緑・黒・橙
- 付箋: クリック配置
- ブックマーク: ツールバーから現在ページ
- エクスポート: JSON または Markdown ダウンロード
- 共有: 期限付きリンク（既定 7 日、最大 30 日）

ハイライト色: 黄 `#FFEB3B`、緑、青、ピンク、橙。

## データと API

CRUD は [プラットフォーム API の注釈](../api/platform.md) を参照。座標は `rects`（PDF ポイント）。描画パスはクライアント側ユーティリティで保持します。

## 権限

作成者のみ PUT/DELETE。共有 GET はリンクを知る人。ログイン中でライセンスが無いと 403 です。
