# ライセンス

> 読者: 開発者
> 最終更新: 2026-09-09
> 関連: [管理 API](../api/admin.md) / [管理画面](admin.md) / [管理者マニュアル](../manuals/admin.md)

## 目的

組織が購入した席をユーザーに割り当て、閲覧可否を決めます。

## 対象ユーザー

- 割当操作: `org_admin`
- 参照: 管理画面に入れるロール、講師向け組織 API
- 消費: 全学習ユーザー（verify）

## 状態

| 項目 | 状態 |
|------|------|
| 管理画面での発行・編集・削除・割当 | ✅ |
| ユーザー単位の割当更新 | ✅ |
| 閲覧前 verify | ✅ |
| 席不足 409 | ✅ |
| オフライントークン | 🔶 API のみ |
| 課金・決済 | ➖ スコープ外 |

## 画面とルート

管理画面 `/licenses`。アカウント画面からもユーザーへライセンスを付け外せます。

## 主な操作

- 教材を選び席数・期間・オフライン可否を設定して作成
- ユーザーを席に乗せる / 外す
- ステータス `active` `expired` `revoked`

学習者側にライセンス一覧画面はありません。本棚に載るかどうかが結果です。

## データと API

エンティティは [ドメインモデル](../domain-model.md)。学習者: `GET /licenses/me` `POST /licenses/verify`。管理: `/admin/licenses*`。

`canAccessContent` は有効ライセンスの割当を見ます。

## 権限

発行と席の付け外しは組織管理者です。content_admin は一覧参照が中心です。
