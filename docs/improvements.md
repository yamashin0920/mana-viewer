## 全体の傾向

最大の課題は **「Mock API と型定義には存在するが、画面に繋がっていない機能」がまだ残っている** ことです。チャンク配信・DRM のコピー/印刷・オフライン同期フラッシュは接続済みです。一方で、管理画面は 3 ページしかなく、seed データにある組織・グループ・端末・LMS・学習進捗はどれも管理できません。

## 1. ビューアの機能不足

### 1.1 根幹がスタブのまま（最優先）

#### 暗号化チャンク配信（接続済み・復号はモック）

`VITE_USE_DEMO_PDF=false` のとき、ビューアは `createViewSession` の `sessionToken` を `X-Session-Token` に載せて `GET /contents/:id/chunks/:page` を呼びます。モックチャンクは PDF バイトを含まないため、検証後に `sample.pdf` へフォールバックします。本番の AES-GCM 復号は未実装です。

#### DRM ポリシー（コピー / 印刷は適用済み）

`allowPrint` / `allowCopy` はビューアで参照し、印刷ショートカットとクリップボード copy/cut を止めます。`allowScreenshot` と暗号的な強制はブラウザでは実現できないため未対応です。アプリ内ハイライト用のテキスト選択は残しています。

#### オフライン同期キューのフラッシュ（実装済み）

起動時と `online` イベントで保留中の進捗・注釈を送信します。注釈 API 失敗時も Dexie へ退避します。

まだ未接続のオフライン機能:

- オフラインパッケージのダウンロード UI が存在しない（Dexie の `offlinePackages` テーブルはスキーマのみで読み書きヘルパーなし）
- Service Worker が存在せず、完全オフライン閲覧ができない
- 端末登録（`/devices`）が未使用
- ライセンス検証の `canDownloadOffline` / `expiresAt` が無視されている

### 1.2 読書・操作機能

ツールバーにあるのはページ送り、ページ番号入力、ズーム ±、単ページ/見開き切替、検索のみです（`viewer/src/components/viewer/ViewerToolbar.tsx`）。PDF リーダーとして期待される以下が不足しています。

| 不足機能 | 内容 |
|---|---|
| フィット表示 | 「幅に合わせる」「ページ全体」がなく手動ズームのみ。開いた瞬間に適切なサイズにならない |
| 連続スクロール表示 | ページ単位の描画のみ |
| ページ回転 | 90° / 180° の回転 UI なし |
| 全画面表示 | なし |
| 先頭・末尾ジャンプ | Home / End キー未対応 |
| ジャンプ履歴 | 目次から飛んだ後に元のページへ戻れない |
| `?page=` ディープリンク | LTI / LMS 連携の前提だが未対応。ルートは `/viewer/:contentId` で `?share=` のみ解釈 |
| 目次のツリー表示 | `level` によるインデントのみで開閉できない |

`mock-api/src/routes/lms.js` の Deep Link は `/viewer?contentId=` を返しますが、アプリのルートは `/viewer/:contentId` で **形式が食い違っています**。

### 1.3 注釈

#### 下線（underline）だけ作成手段がない

型・PDF 上の表示・編集ダイアログ・エクスポートの日本語ラベルまで揃っているのに、作成 UI がありません。

```ts
// viewer/src/types/annotationTools.ts:1
export type AnnotationTool = 'select' | 'marker' | 'pen' | 'sticky'
```

選択ツールバーにも下線ボタンがなく、サイドバーのフィルタタブにも下線がありません。

#### その他の注釈の不足

- **注釈内のテキスト検索がない** — 数十件貯まると目的の注釈を探せない
- **共有の範囲・期限を指定できない** — API は `annotationIds` と `expiresInDays` を受け付けるが、UI は常に空オブジェクトを送信（`viewer/src/pages/ViewerPage.tsx:307`）
- **共有された注釈を取り込めない** — 閲覧専用で自分の注釈として保存できない
- **描画に消しゴム・アンドゥがない**
- **ページメモの位置を指定できない** — 常に座標 `{x:20, y:20}` 固定（`viewer/src/pages/ViewerPage.tsx:417`）
- **PDF 上のメモアイコンをクリックしても編集できない**
- **注釈のページ移動 UI がない** — API の `updateAnnotation` は `page` 変更に対応済み

### 1.4 学習プラットフォームとしての不足

| 不足機能 | 現状 |
|---|---|
| 学習時間の記録 | `totalReadSeconds` が seed と型にあるが、一度も計測・保存・表示されていない |
| 学習統計ダッシュボード | なし |
| 小テスト・確認問題 | なし |
| 読み上げ（TTS） | なし |
| 検索履歴 | なし |
| スクロール位置の復元 | `scrollOffset` に常に `0` を保存しているため、続きから開いてもページ先頭に戻る |
| お気に入り・カスタム本棚 | `shelf-favorites` / `shelf-recent` が API 側にあるが UI なし。「最近読んだもの」はクライアント側で計算 |
| 教材詳細ページ | `description` / `isbn` / `tags` / `version` が seed にあるがカードに出ず、カードから直接ビューアへ遷移 |
| 組織のブランディング表示 | `branding.logoUrl` が seed にあるがヘッダーは固定アイコン |
| xAPI 学習記録の送信 | Mock API のみ |

## 2. UI/UX の問題

### 2.1 アクセシビリティ（最も深刻）

#### モーダルがダイアログとして成立していない

Escape キーは効きますが、`role="dialog"`、`aria-modal`、タイトルとの関連付け、フォーカストラップ、開閉時のフォーカス移動・復帰がすべてありません（`viewer/src/components/ui/Modal.tsx`）。キーボード利用者は背後の要素にタブ移動できてしまいます。メモ・注釈編集・付箋・共有の全ダイアログが該当します。

#### トーストが支援技術に通知されない

`role="status"` も `aria-live` もないため、注釈の保存・削除・エラーが読み上げられません（`viewer/src/components/ui/Toast.tsx`）。

#### フォーカスリングがない

共有 `Button` に `:focus-visible` のスタイルがなく、3 アプリ全体でフォーカスリングを持つのは `PdfLinkLayer` だけです（`viewer/src/components/ui/Button.tsx:33`）。キーボード操作時に現在位置が分かりません。

#### その他

- 管理画面のアイコンのみのボタン（編集・削除）に `aria-label` がない（`admin/web/src/pages/AccountsPage.tsx:225` ほか）
- カラーパレットのスウォッチが `title` のみで `aria-label` なし
- フォームのラベル欠落が多数 — 本棚の検索欄はプレースホルダのみ、管理画面は `<label>` があっても `htmlFor` が繋がっていない
- スキップリンクが 3 アプリともない
- ログインエラーが `role="alert"` を持たない（`auth/web/src/pages/LoginPage.tsx:149`）
- モバイルサイドバーのドロワーに Escape / フォーカストラップ / `role="dialog"` がない
- モバイル FAB に `aria-label` がない

### 2.2 モバイルの操作密度

注釈・ズーム・見開きは狭い画面では「ツール」トレイに入り、ピンチズームもある。検索中もページ送りと注釈は残る。残っているのは次の点です。

- サイドバーを開くボタンがツールバーと FAB に重複している
- 二次ツールは狭い画面でワンタップ余分に必要（意図したトレードオフ）

### 2.3 管理画面が事実上デスクトップ専用

- サイドバーが固定 224px で、ハンバーガーメニューも折り畳みもない（`admin/web/src/components/AdminLayout.tsx:21`）
- テーブルが `overflow-hidden` の中にあり、横スクロールもカード表示のフォールバックもない（`AccountsPage.tsx:203`、`LicensesPage.tsx:259`）
- 6 列あるライセンス一覧はスマートフォンで列が切れて読めない

### 2.4 エラーとフィードバック

- **管理画面の作成・更新・削除ハンドラに try/catch がない** — 初期ロードとライセンス割当だけが例外処理されており、それ以外は API が 400 / 403 を返すと画面が無反応になる
- **`content_admin` ロールの UI 制御がない** — 書き込み系 API は `org_admin` 限定なのに UI ではボタンが全て見え、押しても黙って失敗する
- **削除確認がアプリごとにバラバラ** — ビューアは確認もアンドゥもなしにワンクリックで注釈を削除、管理画面はネイティブの `confirm()`
- **管理画面の送信ボタンにローディング / 無効化がなく二重送信できる**
- **一覧が空のときの表示（EmptyState）が管理画面にない**
- クリップボードのコピー失敗が処理されていない（`ShareAnnotationsDialog.tsx:25`）

### 2.5 デザインシステムの三重管理

Tailwind のトークンが 3 つの `index.css` に複製され、すでに乖離しています。

| トークン / 機能 | viewer | admin | auth |
|---|---|---|---|
| `--shadow-float` | あり | なし | なし |
| アニメーション（`fade-in`, `slide-up`） | あり | なし | なし |
| `.skeleton` | あり | なし | なし |
| `.custom-scrollbar` | あり | なし | なし |
| フォントスムージング | あり | なし | なし |

`Button` と `ThemeToggle` も 3 実装あり、テーマの永続化挙動が違います。

| アプリ | テーマの永続化 | OS 設定の反映 |
|---|---|---|
| viewer | localStorage + Zustand | あり |
| auth | localStorage のみ | なし |
| admin | **なし（React state のみ）** | なし |

**管理画面はリロードするとダークモードが解除されます。** また `Badge` にダークモードのスタイルがありません。

**修正**: 共有パッケージ（`packages/ui` 等）にトークン・`Button`・`ThemeToggle` を切り出し、3 アプリから参照する。

### 2.6 パフォーマンス

- **サムネイルサイドバーが全ページを一度に描画する** — 仮想化も遅延読み込みもないため、200 ページの教材ではキャンバスが 200 枚同時にマウントされる（`ThumbnailSidebar.tsx:44`）
- 注釈一覧も仮想化されていない
- 管理画面の一覧は全件取得で、件数が増えると破綻する

### 2.7 その他

- **i18n レイヤーがない** — 日本語が全面ハードコード。日付書式も 3 箇所でばらばらに `toLocaleDateString('ja-JP')` を記述
- **開発用の資格情報が本番 UI に露出** — ログイン画面に ID/パスワードが表示され（`auth/web/src/pages/LoginPage.tsx:173`）、ビューアヘッダにも開発用ユーザー切替がある
- 「最近読んだもの」の件数リンクが `to="#"` + `preventDefault()` の死んだリンク（`RecentlyReadSection.tsx:33`）
- 注釈編集ダイアログが種別を `highlight` / `drawing` と英語の生値で表示（`EditAnnotationDialog.tsx:65`）
- アイコンボタンが約 32px で、タッチ推奨の 44px を下回る

## 3. 管理画面の不足

現状はアカウント・ライセンス・コンテンツの 3 ページのみで、単一組織向けの MVP という状態です。

### 3.1 画面自体が存在しない領域

| 領域 | バックエンドの状態 | 管理 UI |
|---|---|---|
| 組織・テナント（`maxSeats`, `ssoEnabled`, `mfaRequired`, ブランディング） | seed + 参照 API あり | なし |
| グループ・クラス | seed + `GET/POST /users/.../groups` | なし |
| 本棚・教材配布 | seed + 学習者向け CRUD API | なし |
| 端末管理（登録解除） | seed + `/devices/*` | なし |
| LMS / LTI 設定、名簿同期 | seed + `/lms/*` | なし |
| 学習進捗・分析ダッシュボード | seed に `progress` あり | なし |
| 注釈のモデレーション | seed に `annotations` あり | なし |
| 監査ログ | データモデルすらなし | なし |
| 通知 | なし | なし |
| 組織設定（SSO / MFA / 座席上限） | seed に設定値あり | なし |

B2B の管理コンソールとして特に不足が大きいのは次の 2 点です。

1. **教材をどのグループに配布するかを管理できない** — ライセンス割当で間接的に行うしかない
2. **組織管理者が受講者の学習状況を一切見られない** — 進捗データは seed にあるが出口がない

### 3.2 既存ページの機能不足

#### コンテンツ

- **PDF アップロードがない** — 作成できるのはメタデータのレコードのみで、`fileSizeBytes` は常に 0
- `isbn` / `tags` / `version` / `coverUrl` / `policy.watermarkText` がフォームにない
- 目次（TOC）エディタがない
- DRM ポリシーは `allowPrint` / `allowOffline` / `offlineDays` / `maxDevices` のみで、`allowCopy` / `allowScreenshot` を編集できない

#### ライセンス

- **作成時にステータスが送信されない** — UI に選択肢は出ているが、作成ハンドラがその値を組み立てず更新時のみ反映される（`LicensesPage.tsx:76`）
- 失効・更新のワークフローがない
- `POST /admin/licenses/:licenseId/assign`（一括追加 / 削除）はクライアント関数すら存在せず未使用

#### ユーザー・アカウント

- **`externalId` を編集できない** — LMS 連携のキーになる項目で、名簿同期の実装時に障害となる
- **パスワード再設定フローがない** — 管理者が資格情報を直接書き換える以外に手段がなく、リセットメール送信も初回強制変更もない
- MFA / セッション管理が未対応

### 3.3 運用面の不足

- **ページネーション・ソート・サーバサイド検索・絞り込みがない** — 一覧は全件を一度に返す設計。`mock-api/src/store.js` に `paginate()` が用意されているが未使用
- **複数選択による一括操作がない**
- **CSV の一括インポート / エクスポートがない**
- 更新は毎回全件再取得で、楽観的更新がない
- 送信前のバリデーションがなく、API の 400 頼み

### 3.4 テストの不足

管理画面の資格情報 / ユーザー / ライセンス / コンテンツの CRUD と、ビューアのライセンス拒否・透かしは E2E でカバー済みです。チャンク配信・DRM のコピー/印刷属性もカバーしています。

まだ未カバー、または機能自体が未実装のためテストできない項目です。

- スクリーンショット防止、端末登録、オフラインパッケージ
- 下線注釈の作成、注釈検索、共有の範囲指定
- `?page=` ディープリンク

## アーキテクチャ（着手済み / 残り）

着手済み:

- `@mana/contracts` — 型・ロール・権限の単一ソース。Zod スキーマで書き込み API を実行時検証
- `@mana/auth-client` — SSO / トークン / AuthGuard の共有
- `@mana/dev-data` — seed / credentials のパス結合を 1 モジュールに集約
- mock-api の永続化ポリシーを `admin` / `learner` の二層で明示
- mock-api のトークン検証を `AUTH_API_URL/auth/me` の HTTP introspect に変更
- 暗号化チャンク配信・DRM のコピー/印刷・オフライン同期フラッシュ
- admin のデータ取得を TanStack Query に揃える

まだ残っている構造課題:

- 本物の AES-GCM 復号とページ単位ストリーミング
- OpenAPI ドキュメントの生成（Zod スキーマは用意済み）
- オフラインパッケージ / Service Worker / 端末登録
- 管理画面の組織・グループ・学習進捗ダッシュボード

## 優先度

| 優先度 | 項目 | 理由 |
|---|---|---|
| **P0** | 本物のチャンク復号とストリーミング | モックフォールバックの先。製品の配信経路 |
| **P1** | 管理画面の組織・グループと教材配布 | これがないと B2B の管理者が使う理由が生まれない |
| **P1** | 学習進捗ダッシュボード | 学習プラットフォームの中核。データは既に存在する |
| **P2** | `?page=` ディープリンクと LMS Deep Link の URL 整合 | LTI 連携の前提 |
| **P2** | 下線の作成 UI、注釈検索、共有の範囲指定 | 注釈機能の穴埋め |
| **P2** | フィット表示・回転・全画面・連続スクロール | PDF リーダーとしての基本操作 |
| **P3** | 学習時間の計測、教材詳細ページ、お気に入り本棚 | 体験の底上げ |
| **P3** | i18n レイヤー、CSV 入出力、監査ログ | 中長期の運用要件 |
| **P3** | OpenAPI 生成 | Zod 契約の次段 |
